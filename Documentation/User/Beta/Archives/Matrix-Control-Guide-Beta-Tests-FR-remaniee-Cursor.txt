BIENVENUE
--------------------------------------------------------------------------------

Merci pour votre participation aux bêta-tests du Matrix-Control ! :)

Le Matrix-Control est un éditeur MIDI moderne pour les synthétiseurs Oberheim
Matrix-1000, Matrix-6 et Matrix-6R. Il ne produit pas de son : celui-ci sort
toujours de votre synthé. Le logiciel (application autonome ou plugin) sert
de télécommande à l'écran, pour voir et modifier plus confortablement les
réglages du synthé.

Important : le Matrix-Control n'enregistre pas le son du synthé et ne le
remplace pas. Pour entendre le synthé, il faut toujours brancher sa sortie
audio sur votre interface, votre table de mixage ou vos enceintes.
Le logiciel envoie et reçoit seulement des messages MIDI (réglages, patches).

Ce document n'est pas un cours de synthèse sonore, ni le manuel utilisateur
complet du Matrix-Control. C'est un guide de TESTS : une liste de situations
concrètes à rejouer chez vous, pour vérifier que tout se comporte correctement
sur la version bêta du logiciel, avant la diffusion d'une version finale et
stable par le développeur. Vos retours (surtout les bugs et les moments de
confusion) sont précieux !

Comment utiliser ce guide
-------------------------
Parcourez-le dans l'ordre, du début à la fin. Chaque section correspond à une
étape naturelle : installer, démarrer, brancher le MIDI, éditer, etc.

1. Ouvrez ce fichier dans un éditeur de texte simple (TextEdit, Bloc-notes,
   gedit, etc.), ou imprimez-le.
2. Remplacez [ ] par [x] au fur et à mesure (ou cochez à la main).
3. Si une étape ne s'applique pas chez vous (plugin AU sous Windows,
   BANK UTILITY sans Matrix-1000, etc.), écrivez « sans objet » à côté,
   ou passez à la suite.
4. Notez vos observations dans la zone « Notes » de la section où le problème
   apparaît — pas besoin de revenir en arrière plus tard.
5. Tout le monde n'ira pas jusqu'au bout : c'est normal. Les premières sections
   (installation, démarrage, MIDI, édition de base) sont les plus importantes.
   Si vous vous arrêtez après le parcours rapide, vos retours restent très
   utiles.

Deux rythmes
------------
- Parcours RAPIDE : suivez les sections dans l'ordre jusqu'à la section 16
  (récapitulatif 30-45 min). Idéal pour un premier passage.
- Parcours COMPLET : continuez ensuite avec la section 17 et les détails
  que le parcours rapide n'a fait qu'effleurer.

Une seule combinaison ordinateur + logiciel de MAO (DAW) + synthé suffit.
Tester plusieurs machines est un plus, pas une obligation.

Noms à l'écran
--------------
L'interface du Matrix-Control est en anglais. Les noms de sections, modules
et boutons restent donc en anglais dans ce guide, comme à l'écran :
GETTING STARTED, PATCH EDIT, BANK UTILITY, etc.

Repère rapide dans la fenêtre principale
----------------------------------------
Une fois le logiciel ouvert, la zone centrale s'organise à peu près ainsi :

  +----------------------------------------------------------------------+
  |  Logo MATRIX-CONTROL    |   ports MIDI (FROM SYNTH / TO SYNTH...)    |
  +----------------------------------------------------------------------+
  |                         |                          |                 |
  |  PATCH EDIT             |  MATRIX MODULATION       |  MASTER EDIT    |
  |  - 10 modules de son :  |  (10 bus de modulation)  |  (Matrix-1000   |
  |    DCO, VCF, ENV...     |                          |   seulement ;   |
  |  - 5 afficheurs :       |--------------------------|   grisée sur    |
  |    - 3 enveloppes       |  PATCH MANAGER           |   Matrix-6/6R)  |
  |    - 1 Track Generator  |  - INTERNAL PATCHES      |                 |
  |    - 1 Patch Name       |  - COMPUTER PATCHES      |                 |
  |                         |  - BANK UTILITY          |                 |
  |                         |  - PATCH MUTATOR         |                 |
  +----------------------------------------------------------------------+
  |  Messages en bas de fenêtre                  badge DEVICE (type syn) |
  +----------------------------------------------------------------------+

Vocabulaire utile (le même que dans le manuel utilisateur) :
- Section = grand bloc (PATCH EDIT, MATRIX MODULATION, PATCH MANAGER,
  MASTER EDIT)
- Module = bloc à l'intérieur d'une section (DCO 1, INTERNAL PATCHES,
  PATCH MUTATOR, MIDI, VIBRATO, MISC, BANK UTILITY, etc.)
- Bus de modulation = une des dix lignes de MATRIX MODULATION

Un manuel utilisateur plus détaillé peut accompagner le logiciel ; ce guide
de tests ne le remplace pas.

--------------------------------------------------------------------------------
1.4. Points importants avant de commencer
--------------------------------------------------------------------------------

Ces points évitent de prendre pour des bugs des comportements voulus.

Distribution en ZIP, sans installateur
--------------------------------------
Le Matrix-Control arrive dans une archive ZIP. Vous extrayez l'archive, puis
vous copiez vous-même l'application et/ou les plugins aux endroits habituels
(détail en section 3). Ce n'est pas un oubli : pour cette bêta, il n'y a pas
encore d'installateur du type « Suivant / Suivant / Terminer ».

Messages de sécurité macOS ou Windows
-------------------------------------
Les fichiers de la bêta ne passent pas encore par la certification payante
d'Apple (« notarisation ») ni par la signature éditeur Windows. Résultat
fréquent et NORMAL :

- sous macOS : avertissement du type « développeur non identifié » ;
- sous Windows : écran SmartScreen « Windows a protégé votre PC ».

Ce n'est en général PAS un virus ni un bug du plugin. La section 3 explique
comment continuer (par exemple clic droit → Ouvrir sous macOS).

Écouter le synthé dans l'application autonome sous Windows (ASIO)
-----------------------------------------------------------------
En mode Standalone (l'appli seule, hors DAW), le Matrix-Control peut écouter
le retour audio de votre synthé via l'interface de votre ordinateur.
Sous Windows, cela passe souvent par le pilote audio du système (parfois
appelé WASAPI).

Certaines versions du Matrix-Control proposent aussi ASIO (un autre type de
pilote, fréquent en MAO, pour une latence souvent plus faible). Les premières
versions bêta peuvent ne pas encore inclure ASIO : le développeur attend un
accord de licence avec Steinberg (éditeur de cette technologie). Si ASIO
n'apparaît pas dans la liste audio, ce n'est donc pas forcément un échec —
notez-le et vérifiez que l'écoute fonctionne avec le pilote système.
L'important est d'entendre le synthé et de pouvoir éditer.

Protégez vos patches avant d'écrire dans le synthé
--------------------------------------------------
Certaines étapes demandent d'enregistrer un patch dans la mémoire du synthé
(STORE) ou de generer des variations (PATCH MUTATOR). Si vous tenez à des
patches déjà présents, sauvegardez-les d'abord sur l'ordinateur (module
COMPUTER PATCHES → SAVE AS, fichiers .syx) avant les essais d'écriture.

Si « enregistrer dans le synthé » semble ne rien faire (Matrix-1000)
--------------------------------------------------------------------
Sur Matrix-1000, une protection mémoire ou un verrouillage de banque
(MEMORY PROTECT / BANK LOCK, sur la machine ou dans MASTER EDIT) peut
empêcher l'écriture. Vérifiez cela avant de conclure à un bug.

3. INSTALLATION ET PREMIER LANCEMENT
================================================================================

Le Matrix-Control est fourni sans installateur. Extraire le ZIP, copier les
fichiers, puis éventuellement demander à votre DAW de rescanner les plugins.

--------------------------------------------------------------------------------
3.1. Contenu du ZIP
--------------------------------------------------------------------------------
Selon votre système, vous devriez trouver au moins :

[ ] L'application autonome (Standalone)
[ ] Le plugin VST3
[ ] Sur macOS seulement : le plugin AU (sans objet sous Windows / Linux)
[ ] De la documentation (manuel et/ou ce guide)

Si quelque chose manque, notez le nom exact du ZIP et ce qui est absent.


--------------------------------------------------------------------------------
3.2. Sous macOS (Apple Silicon ou Intel)
--------------------------------------------------------------------------------

Où copier les fichiers :

  Plugin AU   →  ~/Library/Audio/Plug-Ins/Components/
  Plugin VST3 →  ~/Library/Audio/Plug-Ins/VST3/
  Application →  /Applications/
                 (ou à côté du ZIP, si vous préférez)

Étapes :
[ ] Extraire le ZIP
[ ] Copier Matrix-Control.component dans Components
[ ] Copier Matrix-Control.vst3 dans VST3
[ ] (Optionnel) Copier Matrix-Control.app dans Applications
[ ] Après un téléchargement navigateur / GitHub, lever le « drapeau de
    quarantaine ». Dans Terminal (adaptez les chemins) :

      xattr -cr /chemin/vers/Matrix-Control.app \
                /chemin/vers/Matrix-Control.vst3 \
                /chemin/vers/Matrix-Control.component

[ ] Premier lancement : si macOS dit « développeur non identifié »,
    clic droit → Ouvrir, ou autoriser dans Réglages Système.
    C'est attendu pour cette bêta. Ce n'est pas un bug.
[ ] Lancer le Standalone : la fenêtre s'ouvre
[ ] Dans le DAW : rescanner si besoin ; le Matrix-Control apparaît en AU
    et/ou VST3
[ ] Charger le plugin sur une piste instrument / MIDI

Ce qui est normal :
- l'appli et les plugins démarrent ;
- après xattr, plus de message « endommagé » / « damaged » en principe ;
- un avertissement « développeur non identifié » peut encore apparaître :
  clic droit → Ouvrir.

Notes (installation macOS) :


--------------------------------------------------------------------------------
3.3. Sous Windows 10 ou 11
--------------------------------------------------------------------------------

Où copier les fichiers :

  Plugin VST3 →  C:\Program Files\Common Files\VST3\
                 (souvent réservé aux administrateurs)
  Standalone  →  Matrix-Control.exe (ou vous voulez)

Étapes :
[ ] Extraire le ZIP
[ ] Copier Matrix-Control.vst3 vers le dossier VST3 ci-dessus.
    Sans droits administrateur : dossier VST3 utilisateur ou chemin
    « plugins » de votre DAW, puis indiquer ce chemin au DAW et rescanner.
[ ] Lancer Matrix-Control.exe
[ ] Si SmartScreen affiche « Windows a protégé votre PC » :
    Informations complémentaires → Exécuter quand même.
    Normal pour cette bêta (pas de signature éditeur Windows).
[ ] Dans le DAW : rescanner les VST3 ; charger le Matrix-Control
[ ] Sous Windows, un port MIDI est souvent réservé à une seule application.
    Si le Matrix-Control n'ouvre pas le port, fermez l'autre logiciel qui
    l'utilise, puis réessayez.

Ce qui est normal : Standalone et VST3 demarrent ; le plugin apparaît après
rescan.

4. PREMIER LANCEMENT : ASSISTANT « GETTING STARTED »
================================================================================

Au premier lancement (ou si la configuration n'est pas terminée), le
Matrix-Control peut ouvrir l'assistant GETTING STARTED : apparence, MIDI
vers le synthé, clavier, et — en Standalone seulement — écoute audio.

Pour le relancer plus tard : logo MATRIX-CONTROL → SETTINGS… → onglet
GETTING STARTED → RUN SETUP AGAIN
(ou laisser SETUP WIZARD sur SHOW WHEN INCOMPLETE).

--------------------------------------------------------------------------------
4.1. Écran d'accueil
--------------------------------------------------------------------------------
[ ] La fenêtre GETTING STARTED s'ouvre (seule, ou après RUN SETUP AGAIN)
[ ] CONTINUE passe à la suite
[ ] CONFIGURE LATER ferme sans tout marquer comme terminé
    (pratique pour finir plus tard dans Settings)

--------------------------------------------------------------------------------
4.2. Étapes communes (plugin et Standalone)
--------------------------------------------------------------------------------
[ ] STEP 1 / USER INTERFACE : essayez UI SCALE (taille) et SKIN (apparence).
    La fenêtre se met a jour.
[ ] STEP 2 / SYNTH COMMUNICATION : choisissez SYNTH FROM / SYNTH TO,
    regardez le badge DEVICE, confirmez ou choisissez EPROM TYPE.
[ ] STEP 3 / MIDI KEYBOARD :
    - En plugin : les notes viennent du DAW ; pas de liste KEYBOARD FROM.
      L'étape se termine avec FINISH.
    - En Standalone : choisissez KEYBOARD FROM, ou SKIP si pas encore de
      clavier maître. Ensuite vient l'audio.

--------------------------------------------------------------------------------
4.3. Standalone seulement — STEP 4 / AUDIO
--------------------------------------------------------------------------------
[ ] Choisissez votre interface audio
[ ] Choisissez les canaux d'écoute du retour synthé (SYNTH FROM dans l'onglet
    AUDIO — ce n'est PAS le même « SYNTH FROM » que le port MIDI)
[ ] FINISH ferme l'assistant

Résultat attendu : vous pouvez terminer même si le MIDI n'est pas encore
parfait. Les étapes « terminées » ne forcent pas la détection du synthé.

Notes (GETTING STARTED) :


================================================================================
5. BRANCHER LE SYNTHÉ ET ÉTABLIR LA COMMUNICATION MIDI
================================================================================

Étape la plus importante. Tant que le synthé n'est pas reconnu, une grande
partie de l'éditeur reste verrouillée — c'est voulu, pour ne pas envoyer
de changements « à l'aveugle ».

Préparez : câbles MIDI dans les deux sens, synthé allumé.

--------------------------------------------------------------------------------
5.1. Choisir les ports MIDI
--------------------------------------------------------------------------------
[ ] Réglez SYNTH FROM et SYNTH TO (bandeau FROM SYNTH / TO SYNTH, ou
    SETTINGS → MIDI & DEVICE, ou GETTING STARTED étape 2)
[ ] Quand du MIDI circule, les voyants à côté des listes clignotent
[ ] En bas a droite, le badge DEVICE affiche Matrix-1000, Matrix-6, etc.
    (un Matrix-6R peut apparaître comme Matrix-6 : notez-le si c'est le cas)
[ ] Si NOT CONNECTED : suivez le message en bas de fenêtre
    (câbles, ports, éteindre/rallumer le synthé)

--------------------------------------------------------------------------------
5.2. Édition verrouillée puis débloquée
--------------------------------------------------------------------------------
[ ] Sans détection correcte, l'édition reste verrouillée (normal)
[ ] Une fois le synthé reconnu, PATCH EDIT et les zones utiles se débloquent

--------------------------------------------------------------------------------
5.3. Sous Windows : port MIDI déjà pris
--------------------------------------------------------------------------------
[ ] Si le port refuse de s'ouvrir : fermez l'autre application / DAW qui
    l'occupe, ou utilisez un port MIDI virtuel, puis réessayez

Résultat attendu : DEVICE reconnu, édition possible, pas de cascade
d'erreurs si les ports sont bons.

Notes (MIDI) :


================================================================================
6. ÉDITER UN PATCH — SECTION « PATCH EDIT »
================================================================================

Une fois le synthé détecté, chargez un patch via le module INTERNAL PATCHES
(dans la section PATCH MANAGER — détail section 8), puis travaillez dans
la section PATCH EDIT.

Chaque mouvement à l'écran est envoyé au synthé : vous devez entendre le
changement sur la machine.

Modules typiques dans PATCH EDIT :
  DCO 1 / DCO 2     oscillateurs
  VCF/VCA           filtre et volume
  FM/TRACK          FM + Track Generator
  RAMP/PORTAMENTO   rampes, portamento, mode clavier
  ENV 1 / 2 / 3     enveloppes
  LFO 1 / LFO 2     oscillateurs lents
  PATCH NAME        nom du patch (8 caractères)

--------------------------------------------------------------------------------
6.1. Gestes représentatifs
--------------------------------------------------------------------------------
[ ] Dans le module DCO 1, changez un paramètre (forme d'onde, désaccord…) :
    le son change
[ ] Dans VCF/VCA, bougez la fréquence de coupure ou la résonance : le son
    change
[ ] Sur une enveloppe (ENV), déplacez un point a la souris
[ ] Dans FM/TRACK, déplacez un point du Track Generator a la souris

--------------------------------------------------------------------------------
6.2. Boutons I / C / P sur un module
--------------------------------------------------------------------------------
Sur plusieurs modules, l'en-tête propose :
  I = Init   (remettre le module a des valeurs par défaut)
  C = Copy   (copier vers le presse-papiers)
  P = Paste  (coller depuis le presse-papiers)

[ ] I réinitialise le module
[ ] C puis P sur un module compatible fonctionne
[ ] Sur un module incompatible, P est grisé ; un clic peut afficher un
    message en bas de fenêtre

--------------------------------------------------------------------------------
6.3. Annuler / rétablir
--------------------------------------------------------------------------------
[ ] Annuler (Cmd+Z sous macOS, Ctrl+Z sous Windows/Linux) revient en arrière
[ ] Rétablir (Cmd+Shift+Z / Ctrl+Shift+Z) restaure
[ ] Charger un autre patch efface cet historique d'annulation

--------------------------------------------------------------------------------
6.4. Nom du patch (PATCH NAME)
--------------------------------------------------------------------------------
[ ] L'afficheur PATCH NAME montre le nom actuel (8 caractères)
[ ] Double-clic pour renommer quand c'est autorisé :
    - Matrix-1000 : possible surtout sur les banques 0 et 1 (mémoire
      réinscriptible) ; souvent impossible sur les banques 2 a 9 (usine)
    - Matrix-6/6R : en général possible (pas de banques ROM du même type)
[ ] Sur une banque ou le renommage est refusé, le double-clic ne doit pas
    ouvrir d'édition (ou le champ reste bloqué) — notez ce que vous voyez
[ ] Le nom se met aussi a jour au chargement d'un patch ou après certaines
    actions du PATCH MUTATOR

Résultat attendu : édition audible, annulation cohérente, pas de fermeture
intempestive.

Notes (PATCH EDIT) :


================================================================================
7. MATRICE DE MODULATION — SECTION « MATRIX MODULATION »
================================================================================

C'est le « câblage » interne du synthé : on relie une source (LFO, enveloppe,
vélocité…) à une destination (filtre, hauteur…). Dix bus (lignes),
numéros 0 à 9.

Préparez : synthé détecté, un patch chargé.

[ ] Sur un bus : SOURCE, AMOUNT, DESTINATION (autre que NONE)
[ ] Jouez une note : la modulation s'entend / se sent
[ ] Le bouton I sur un bus remet ce bus à zéro
[ ] Réordonnez deux bus en glissant le numéro # : départ gris, arrivée rouge ;
    les contenus s'échangent, les numéros restent 0 a 9
[ ] Annuler après ce réordonnancement revient d'une étape

Résultat attendu : bus éditables, réordonnancement stable.

Notes (MATRIX MODULATION) :


================================================================================
8. PATCHES DANS LE SYNTHÉ ET SUR L'ORDINATEUR — SECTION « PATCH MANAGER »
================================================================================

La section PATCH MANAGER regroupe notamment :
  INTERNAL PATCHES   mémoire du synthé
  COMPUTER PATCHES   fichiers .syx sur l'ordinateur
  BANK UTILITY       banques (Matrix-1000)
  PATCH MUTATOR      variations (section 11)

--------------------------------------------------------------------------------
8.1. Module INTERNAL PATCHES (mémoire du synthé)
--------------------------------------------------------------------------------
[ ] Les boutons < et > changent de patch ; le Matrix-Control relit le patch
    depuis le synthé
[ ] Double-clic sur le numéro de patch : saisie directe 0 à 99
[ ] STORE enregistre dans l'emplacement courant
    (Matrix-1000 : surtout banques 0 et 1, mémoire réinscriptible)
[ ] Matrix-1000, banques 2 a 9 (mémoire d'usine) : INIT, PASTE et STORE
    grisés — c'est normal
[ ] Si vous avez modifié un patch sans STORE ni sauvegarde fichier, un
    dialogue « Unsaved patch » peut proposer Cancel / Discard / Store /
    Save : vérifiez que les choix sont clairs

--------------------------------------------------------------------------------
8.2. Module COMPUTER PATCHES (fichiers sur le disque)
--------------------------------------------------------------------------------
[ ] OPEN : choisir un dossier de patches
[ ] SAVE AS : créer un nouveau .syx ; SAVE : enregistrer dans le fichier
    déjà associé
[ ] Parcourir la liste avec < / > et recharger un .syx
[ ] Si « Patch name mismatch » (nom interne ≠ nom de fichier) :
    Internal / Filename / Cancel se comportent de façon compréhensible

Résultat attendu : navigation fluide, STORE sur mémoire réinscriptible OK,
fichiers .syx lisibles, pas d'écrasement surprise.

Notes (INTERNAL / COMPUTER PATCHES) :


================================================================================
9. BANQUES DU MATRIX-1000 — MODULE « BANK UTILITY »
================================================================================

Le Matrix-1000 organise ses patches en 10 banques (0 à 9) de 100 patches.
Le module BANK UTILITY (dans PATCH MANAGER) sert à changer de banque.

Sur Matrix-6/6R : ce module est entièrement grisé (pas de banques). C'est voulu.

[ ] Matrix-6/6R : BANK UTILITY est grisé (sans objet sur Matrix-1000)
[ ] Matrix-1000 : boutons 0 a 9 changent la banque ; le patch courant est relu
[ ] Banques 0 et 1 : écriture possible (STORE, etc.)
[ ] Banques 2 a 9 : lecture seule pour INIT / PASTE / STORE dans
    INTERNAL PATCHES
[ ] Si votre version propose import / export de banque : essayez une fois
    avec prudence, après avoir sauvegardé vos sons importants

Résultat attendu : changement de banque fiable ; banques d'usine protégées ;
zone grisée sur Matrix-6/6R.

Notes (BANK UTILITY) :


================================================================================
10. RÉGLAGES GLOBAUX — SECTION « MASTER EDIT » (Matrix-1000)
================================================================================

MASTER EDIT regroupe des réglages pour tout le synthétiseur (canal MIDI,
vibrato global, accordage…), pas pour un seul patch.

Modules : MIDI, VIBRATO, MISC.

Sur Matrix-6/6R, toute cette colonne est grisée — c'est voulu.

[ ] Matrix-6/6R : MASTER EDIT est grisé (sans objet sur Matrix-1000)
[ ] Matrix-1000 : modules MIDI, VIBRATO et MISC visibles et éditables
[ ] Changez le CHANNEL MIDI avec prudence : comportement cohérent
[ ] Bouton I sur un module : dialogue RESET MASTER MODULE?
    Reset / Cancel fonctionnent
[ ] Un réglage master influence le comportement general, quel que soit
    le patch chargé

Résultat attendu : édition possible sur Matrix-1000 seulement.

Notes (MASTER EDIT) :


================================================================================
11. MODULE « PATCH MUTATOR »
================================================================================

Le PATCH MUTATOR (dans PATCH MANAGER) crée des variations aléatoires
contrôlées du patch courant — pratique pour explorer des timbres.

Préparez : synthé détecté, patch chargé. Sauvegardez d'abord si le son de
départ vous est précieux.

Commutateurs de modules (choisir ce qui entre dans la mutation) :
  D1  = DCO 1
  D2  = DCO 2
  F/A = filtre / VCA (VCF/VCA)
  F/T = FM / Track Generator
  R/P = Ramp / Portamento
  E1 / E2 / E3 = enveloppes 1, 2, 3
  L1 / L2 = LFO 1 et 2
  MM  = matrice de modulation (MATRIX MODULATION)

Boutons principaux :
  MUTATE   crée une nouvelle variation et l'envoie au synthé
  RETRY    autre tirage a partir du même point de départ
  HISTORY  + < / >  parcourt les variations de la session
  C        Compare : compare au départ et VERROUILLE le reste de l'édition
           tant qu'il est actif
  D        Delete : supprime l'entrée sélectionnée dans l'historique
  F        Flush : vide l'historique de la session
  E        Export : exporte la session en fichiers .syx

[ ] Au moins un commutateur (D1, D2, F/A, …, MM) est activé
[ ] Réglez AMOUNT et RANDOM autrement que les défauts, puis MUTATE :
    variation audible / visible envoyée au synthé
[ ] RETRY propose une autre variante
[ ] HISTORY < / > parcourt la session
[ ] C (Compare) verrouille l'édition ; un message en bas de fenêtre le rappelle
[ ] Désactiver Compare restaure l'édition
[ ] D et F se comportent comme attendu (suppression / vidage) — avec prudence
[ ] E exporte la session ; rouvrir via COMPUTER PATCHES → OPEN
[ ] Dialogues (historique plein, mutations non exportées, dossier déjà
    existant) : choix clairs, pas de perte silencieuse

Résultat attendu : mutations audibles, Compare qui bloque bien, export
rechargeable.

12. APPLICATION AUTONOME ET PLUGIN
================================================================================

Deux façons d'utiliser le Matrix-Control :
- plugin dans le DAW (VST3 partout ; AU en plus sous macOS) ;
- application autonome (Standalone), sans DAW.

--------------------------------------------------------------------------------
12.1. En plugin
--------------------------------------------------------------------------------
[ ] Le plugin se charge sans planter
[ ] Les notes arrivent via la piste du DAW (KEYBOARD FROM = HOST)
[ ] Le son du synthé revient sur une piste audio separee
    (le plugin ne génère pas l'audio du synthé)
[ ] GETTING STARTED n'impose pas d'étape Audio
[ ] SETTINGS… accessible (logo MATRIX-CONTROL ou raccourci)

--------------------------------------------------------------------------------
12.2. En Standalone
--------------------------------------------------------------------------------
[ ] La fenêtre autonome s'ouvre ; SETTINGS → AUDIO disponible
[ ] Vous entendez le retour du synthé via l'interface choisie
[ ] KEYBOARD FROM sélectionnable (ou SKIP dans Getting Started)
[ ] Si INPUT GAIN / monitoring apparaît dans le bandeau : il réagit

--------------------------------------------------------------------------------
12.3. Écoute audio sous Windows (Standalone)
--------------------------------------------------------------------------------
Rappel ASIO : voir section 1.4 (accord de licence Steinberg en cours ;
ASIO peut manquer dans les premières bêtas).

[ ] Avec le pilote système (souvent WASAPI) : entrée audible, latence
    acceptable pour éditer
[ ] Si ASIO apparaît dans la liste : périphérique sélectionnable, audio OK
[ ] Si ASIO n'apparaît pas : notez-le et continuez avec le pilote système
    — ce n'est pas forcément un échec pour cette premiere bêta

Résultat attendu : plugin et Standalone utilisables ; au minimum, écoute
Standalone via les pilotes système.

13. ABLETON LIVE SOUS WINDOWS — IMAGE FLOUE (« AUTO-SCALE »)
================================================================================

Uniquement sous Windows + Ableton Live + plugin VST3 du Matrix-Control.
(Sous macOS, cette option n'existe pas : section sans objet.)

Problème connu sous Windows : Live propose souvent
« Auto-Scale Plugin Window ». Quand c'est activé, l'interface du
Matrix-Control peut apparaître floue dans le plugin, quelle que soit
UI Scale. Le Standalone reste net sur la même machine.

Comment désactiver l'option :
[ ] Chargez d'abord le Matrix-Control sur une piste dans Live
[ ] Clic droit sur la barre de titre du device (en bas, dans la vue
    Device) → désactiver « Auto-Scale Plugin Window »
[ ] Rechargez le device
[ ] Vérifiez que l'interface VST3 est nette
[ ] Comparez avec le Standalone (doit rester net)

Ne cherchez pas cette option dans le navigateur (Browser) à gauche :
un clic droit sur Matrix-Control dans la liste des plug-ins ne montre
en général que le regroupement et les couleurs, pas Auto-Scale.

14. POINTS CONNUS À VÉRIFIER (PAS TOUJOURS DES BUGS)
================================================================================

Certains comportements surprennent. Confirmez ce que vous voyez.

[ ] Unison (surtout Matrix-1000) : dans le module RAMP/PORTAMENTO (et
    réglages Unison liés, y compris côté MASTER EDIT / MISC selon votre
    machine), activez / réglez Unison.
    Le rendu peut être contre-intuitif : ce que l'on croit commander à
    l'écran ne correspond pas toujours à ce que l'on entend. Cela vient
    surtout de la façon dont le Matrix-1000 gère l'Unison côté machine
    (plusieurs notions liées : mode clavier, Unison master, etc.), pas
    d'un simple bug d'affichage du Matrix-Control.
    Decrivez ce que vous voyez et entendez.
[ ] Keyboard Mode : toujours dans RAMP/PORTAMENTO, changez le mode clavier.
    Un comportement bizarre côté firmware du synthé est connu ; il est
    souvent contourné ou résolu avec une EPROM Untergeek v1.21.
    Notez votre EPROM et ce qui se passe (notes collées, mode qui ne
    « prend » pas, etc.).
[ ] MEMORY PROTECT / BANK LOCK : s'ils sont actifs, STORE peut sembler
    cassé — vérifiez avant de signaler un bug.
[ ] Sur Matrix-6/6R : MASTER EDIT et BANK UTILITY grisés (voulu)
[ ] Avertissements macOS / Windows au lancement : souvent normaux
    (sections 1.4 et 3)
[ ] Un Matrix-6R peut s'afficher comme Matrix-6
[ ] ASIO peut manquer (section 1.4) — testez l'écoute avec le pilote système
