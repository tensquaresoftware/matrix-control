À QUOI SERT CE DOCUMENT ?
--------------------------------------------------------------------------------

Ce texte sert pour la vie courante du produit : un bug, un comportement
étrange ou une question précise, hors session de tests bêta structurée.

Pendant une campagne de tests bêta, préférez le guide de tests rempli
(Matrix-Control-Guide-de-tests-beta-FR.txt) : il contient déjà la fiche de
session, les cases cochées et les notes. Joignez simplement ce fichier
par email (voir la section « Envoyer vos résultats » du guide).

QUELLES INFORMATIONS INDIQUER DANS VOTRE MESSAGE ?
--------------------------------------------------------------------------------

Indiquez au minimum :

1. Titre court : contexte et résumé du problème
   (ex. « Matrix-1000 : STORE grisé sur banque 0 »)
2. Version du Matrix-Control (logo → ABOUT…)
3. Système (nom + version) et type d'ordinateur
4. Standalone ou plugin (AU / VST3) + DAW et sa version si besoin
5. Synthé (Matrix-1000 / 6 / 6R) + EPROM / firmware si connu
6. Étapes pour reproduire, numérotées
7. Ce que vous attendiez, et ce qui s'est passé
8. Toujours, ou seulement parfois ?
9. Texte exact du message en bas de fenêtre ou du dialogue
10. Si possible : une capture d'écran

Inutile d'envoyer mots de passe, licences, ou une copie entière du disque.
